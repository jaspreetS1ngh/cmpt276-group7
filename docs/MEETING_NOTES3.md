1. Iteration 2 Scope
The group finalized the following features for Iteration 2 based on the project requirements:

- Route Sharing
Users can view, share, and manage routes with friends.
Includes a share modal with friend list and copy link functionality.
Routes display with stops and descriptions.
This serves as the foundation for future social features.

- Save Location
Users can save favorite places to a personal list.
Saved locations are stored in a database and displayed on the map.
Users can view, manage, and remove saved locations.
This is the first (and most important) feature from our original proposal.

3. Git Workflow Agreement
The group agreed on the following Git workflow to manage collaboration:

Branch Structure:
- main: Production-ready code
- feature/route-sharing-frontend (Andrew TJ)
- feature/route-sharing-backend (asiandude121)
- feature/save-location-frontend (shindh0717)
- feature/save-location-backend (jaspreetS1ngh)

Process:
- Create branch from main for your feature
- Commit regularly with clear messages
- Push branch to GitHub
- Create Pull Request (PR) to merge into main
- At least 1 team member must review and approve PR
- No direct pushes to main branch

Commit Message Format:
- feat: New feature
- fix: Bug fix
- docs: Documentation changes
- test: Adding tests
