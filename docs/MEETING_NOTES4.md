1. Iteration 3 Scope
The group finalized the following features for Iteration 3 (final iteration) based on the project requirements:

Ranking System
Users can rate and review locations (1-5 stars).
Locations are ranked based on average ratings.
Reviews include text comments from users.
Helps users discover the best spots in their area.
This is the fourth feature from our original proposal.

Traffic Updates
Users can view real-time traffic information on the map.
Traffic data is displayed using color-coded routes (green, yellow, red).
Helps users avoid traffic congestion when planning routes.
Provides estimated travel times with traffic conditions.
This is an additional feature to enhance the user experience.

3. Git Workflow Agreement
The group agreed on the following Git workflow to manage collaboration:

Branch Structure:
- main: Production-ready code
- feature/ranking-frontend (Andrew TJ)
- feature/ranking-backend (Aveer)
- feature/traffic-frontend (shindh0717)
- feature/traffic-backend (jaspreetS1ngh)
- feature/route-sharing-updates (asiandude121)

Process:
- Create branch from main for your feature
- Commit regularly with clear messages
- Push branch to GitHub
- Create Pull Request (PR) to merge into main
- At least 1 team member must review and approve PR
- No direct pushes to main branch

Commit Message Format:
- feat: New feature
- fix: Bug fix
- docs: Documentation changes
- test: Adding tests
